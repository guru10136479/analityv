# OPL Manager Android

Um aplicativo Android profissional para gerenciar jogos do OPL (Open PS2 Loader) com suporte completo a capas, metadados e organização de biblioteca.

## 📱 Funcionalidades

- ✅ Listar e gerenciar jogos OPL
- ✅ Gerenciamento de capas (thumbnails/covers)
- ✅ Organização por categorias
- ✅ Edição de metadados dos jogos
- ✅ Busca e filtros avançados
- ✅ Modo claro/escuro
- ✅ Sincronização com dispositivos
- ✅ Backup e restauração

## 🛠️ Stack Tecnológico

- **Linguagem**: Kotlin
- **Arquitetura**: MVVM
- **UI**: Jetpack Compose + Material Design 3
- **Banco de Dados**: Room
- **Injeção de Dependência**: Hilt
- **Coroutines**: Kotlin Coroutines
- **Networking**: Retrofit + OkHttp

## 📋 Requisitos

- Android API 24+ (Android 7.0)
- 50MB de espaço livre
- Conexão de rede (para sincronização)
